# Lehrerplaner

Tablet-App (PWA) für Unterrichtsplanung und Notenverwaltung: Schuljahreskalender mit Handschrift (S Pen), Stundenplan mit Gültigkeitszeiträumen, Klassenlisten, Noten in Prozent (IHK-Schlüssel), Excel-Export, optionale Verschlüsselung.

Alle Daten bleiben lokal auf dem Gerät (IndexedDB). Dieses Repository enthält nur den Programmcode.

Installation: Seite in Chrome öffnen → Menü → „App installieren“.
